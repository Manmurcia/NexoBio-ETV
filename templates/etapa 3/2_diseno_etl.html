2. Diseño del Paquete ETL (SSIS)

El paquete contiene tres Data Flow Task, uno por fuente. No tienen restricciones de precedencia entre sí porque cargan tablas de staging independientes, de modo que SSIS puede ejecutarlos en paralelo. Todos están conectados a la misma base (.\SQLEXPRESS.DB_ENFERMEDADES_ETV); los dos flujos que leen CSV utilizan además un administrador de conexiones de archivo plano.

Data Flow — Perfil Clínico (flujo principal)

Lee el staging, elimina duplicados, deriva columnas limpias y bifurca los registros según su validez.

OLE DB Source lee [dbo].[stg_perfil_clinico]
Sort ordena por EDAD, SEXO, NACIONALIDAD, REGIMEN_DE_AFILIACION, CODIGO_CIE10, NOMBRE_CIE10, CICLO_DE_VIDA; elimina duplicados (1.377.630 → 729.765 filas)
Derived Column crea 6 columnas nuevas (sexo_limpio, regimen_limpio, edad_int, cod_cie10_corto, nacionalidad_cast, cie10_diagnostico_cast) sin sobrescribir las originales
Conditional Split Registros_Validos: edad_int >= 0 && edad_int <= 110; salida por defecto Registros_Atipicos
OLE DB Destination → tbl_perfil_clinico_final (729.758 filas)
OLE DB Destination 1 → tbl_revision_calidad (7 filas)

Data Flow — SIVIGILA Nacional y Cundinamarca

Src_Nacional_Cundinamarca_CSV (Flat File Source) → Conv_Tipos_SIVIGILA (Data Conversion: anio/conteo a entero; cod_municipio, municipio, evento y las dos tasas como cadena) → Dest_Tabla_SIVIGILA (OLE DB Destination, carga rápida) → [dbo].[stg_regional_cundinamarca]

1.640 filas recibidas → 1.640 cargadas, sin pérdidas.

Data Flow — Datasets Globales (OMS)

Src_OMS_Brotes_CSV (Flat File Source) → Conv_Tipos_OMS (Data Conversion a Unicode DT_WSTR: Year, Disease, Country, iso2, iso3, unsd_region, who_region) → Dest_Stg_OMS_Brotes (OLE DB Destination, carga rápida) → [dbo].[stg_oms_brotes]

3.566 filas recibidas → 3.566 cargadas, sin pérdidas.

Los destinos usan carga rápida de tabla o vista (fast load) con bloqueo de tabla y comprobar restricciones activados esencial para insertar en bloque cerca de 730 mil registros en lugar de fila por fila, y para que la base valide sus reglas de integridad al cargar.
