1. Diagnóstico y Reglas de Tratamiento

A partir del inventario de problemas de calidad identificado en la Etapa 2, se definieron reglas de tratamiento específicas por variable, indicando el campo afectado, la acción de tratamiento y su justificación técnica. Estas reglas son la base del diseño del paquete ETL en SQL Server Integration Services (SSIS) presentado en la sección siguiente.

PERFIL_EPIDEMIOLOGICO_ANUAL.csv 98.322 filas
Campo Problema Acción de tratamiento (componente SSIS) Justificación
Fila completa 42.723 duplicados exactos Unicidad Sort (Remove rows with duplicate sort values) sobre todas las columnas Los duplicados alteran sumatorias e indicadores de morbilidad; se conserva solo la primera ocurrencia.
REGIMEN DE AFILIACION 18 variantes de capitalización → 8 categorías reales Consistencia Derived Column (UPPER/TRIM) + Lookup contra tabla de homologación Uniformiza texto libre a categorías comparables sin descartar registros.
NACIONALIDAD 13 variantes → 8 categorías reales Consistencia Derived Column (UPPER/TRIM) + Lookup de homologación Mismo problema de consistencia textual que Régimen de Afiliación.
CICLO DE VIDA / MES Columnas desalineadas: el mes real está en "CICLO DE VIDA" Validez / Estructura Derived Column para reasignar: mes_real = [CICLO DE VIDA], subgrupo_causa = [MES] Corrige el error estructural de origen antes de cualquier análisis posterior.
CODIGO CIE10 1 valor nulo Completitud Conditional Split: ISNULL([CODIGO CIE10]) → rama "a revisión" Volumen mínimo; no se infiere un diagnóstico clínico, se envía a revisión manual.
SALUD.xlsx 63.978 filas
Campo Problema Acción de tratamiento (componente SSIS) Justificación
Encabezado Título institucional desplaza el encabezado real a la fila 12 Validez / Estructura Excel Source configurado con rango desde fila 12, o Script Component que descarta las primeras 11 filas Sin esto, todo el archivo se lee con encabezados "Unnamed".
DATO_NUMERICO 7 nulos Completitud Conditional Split → rama "a revisión" Volumen bajo; no se imputa un indicador oficial sin respaldo.
DATO_NUMERICO (tasa incidencia) 19 atípicos (hasta 18.640 casos/100k hab.) Exactitud Derived Column con flag de atípico (umbral estadístico) + Conditional Split → rama "a revisión" No se descarta: puede ser un brote real en municipio pequeño; requiere validación humana.
CUALITATIVO 30.986 nulos (columna secundaria, >40%) Completitud Conditional Split a nivel de columna: si % nulos > 40% se excluye del Data Flow Columna no siempre aplica; eliminarla evita ruido sin perder registros completos.
sivigila_dengue.csv 53.813 filas
Campo Problema Acción de tratamiento (componente SSIS) Justificación
cod_mun_d y columnas de síntomas/clínicas "SD" usado como pseudo-nulo (hasta 92% de filas) Completitud Derived Column: REPLACE(campo, "SD", NULL) (o "NO REPORTADO" en categóricas clínicas) "SD" no es una categoría válida; tratarlo como nulo explícito evita contarlo como dato real.
edad_ Edades inverosímiles (112, 122, 174 años) Exactitud Derived Column (edad_ > 110 OR edad_ < 0) + Conditional Split → rama "a revisión" Consistente con el límite biológico 0-110 definido en Etapa 2; evita sesgar la edad promedio.
nombre_barrio "SIN INFORMACION" imputado (3.287 filas) Completitud Derived Column: REPLACE("SIN INFORMACION", NULL) Es un placeholder de texto libre, no un valor real.
Datos_de_Vigilancia_en_Salud_Publica_de_Colombia.csv 241.746 filas
Campo Problema Acción de tratamiento (componente SSIS) Justificación
ANO, COD_MUN_O Texto con separador de miles ("2,012") en vez de número Validez Derived Column (REPLACE(campo, ",", "")) + Data Conversion a entero (DT_I4) Necesario para poder tipificar y operar numéricamente sobre el campo.
Municipio_ocurrencia "MUNICIPIO DESCONOCIDO" genérico (4.605 filas) Completitud Derived Column: normalizar a NULL explícito Diferencia claramente "sin dato" de un municipio real.
Departamento_ocurrencia Categorías no geográficas mezcladas ("EXTERIOR", "PROCEDENCIA DESCONOCIDA") Validez Lookup contra catálogo DANE de departamentos → No Match Output → Conditional Split a "a revisión" Separa geografía válida de categorías administrativas especiales.
disease_outbreaks_HDX.xlsx 3.566 filas  /  Public_Use_Ixodes_County_Table_2023.xlsx 7 hojas
Campo Problema Acción de tratamiento (componente SSIS) Justificación
who_region, Definition, unsd_region/subregion, iso2 Nulos, bajo volumen (6 a 266 filas) Completitud Conditional Split → "a revisión" si el campo es clave; se deja nulo si es secundario Volumen bajo, no justifica descartar el registro completo.
Encabezados (7 hojas Ixodes) Título institucional genera columnas "Unnamed" Validez / Estructura Excel Source con fila de inicio correcta por hoja, o Script Component de limpieza previa Necesario en las 7 hojas para que el Data Flow lea columnas reales.
Todo registro enviado a la rama "a revisión" conserva el valor original de la fila más un campo adicional motivo_revision, para garantizar trazabilidad y evitar pérdidas de información sin explicación.
